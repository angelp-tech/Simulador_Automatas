# Simulador de Autómatas Finitos

## Descripción
Simulador de autómatas finitos deterministas (AFD) desarrollado en Python, que permite construir autómatas, visualizar su representación gráfica, consultar palabras reconocidas y probar cadenas ingresadas por el usuario.

## Funcionalidades
- Construcción de autómatas finitos.
- Visualización de la tabla de transiciones.
- Representación gráfica dinámica del autómata.
- Búsqueda de las cinco palabras reconocidas más cortas.
- Visualización de recorridos entre estados.
- Prueba de cadenas ingresadas por el usuario.
- Identificación de símbolos inválidos.

## Tecnologías utilizadas
- Python
- NetworkX
- Matplotlib

## Requisitos
- Python 3.
- NetworkX.
- Matplotlib.

## Instalación
Instalar las librerías necesarias:

```bash
pip install networkx matplotlib
```

## Ejecución
Ejecutar desde la terminal:

```bash
python main.py
```

## Menú del programa
1. Construir autómata.
2. Mostrar palabras reconocidas.
3. Probar una palabra.
4. Salir.

## Ejemplo de uso
Construir un autómata cuyo lenguaje acepta palabras que terminan en `ab`. Después, utilizar el módulo de palabras reconocidas y el módulo de prueba de palabras para comprobar cadenas.
